# 分镜 v1:ORCHIS MX-7(TikTok 竖屏,12 秒)

对标:ref-video\ 里作者的四条视频。结构相同:开场 → 只拆一个部件 → 整体爆炸 → 收尾冲向镜头。我们照这个结构做,部件选腹部。
参考方法:用 ffmpeg 每 0.5 秒抽一帧,拼成缩略图再看(Part1 蜘蛛、Part3 章鱼、Part4 黄蜂最有用)。

## 规格
- 成片:1080×1920,60fps,12 秒;粗版可以 540×960、30fps。
- 页面文字用英文。
- 所有动画由一个 JSON 脚本驱动;物体、页面、光标、音效读同一份脚本。

## 页面布局(竖屏)
TikTok 底部约 20% 会被文案遮住,右侧约 12% 是按钮,顶部约 7% 是状态栏,这些区域不放关键信息。
- y 约 150–420:左上品牌标识、右上 "Live sim" 标签;居中产品名加型号(ORCHIS MX-7,洋红色)、大标题 "Robotic Mantis, Taken Apart"、短下划线、日期、一排带播放图标的按钮(Head、Scythe、Abdomen、Teardown、Release)。
- y 约 420–1320:舞台,物体居中。
- y 约 1340–1460:4 张小卡片横排(例如 STRIKE、SPRING PRELOAD、COIL TEMP、BATTERY,各配波形、进度条、分段条、电量条的小图)。
- y 约 1480–1530:状态条(状态文字、进度条、时间码)。
- 引线标注贴近物体,不要出现在安全区外。
- 背景:近白,极淡的洋红渐变,极淡的同心轨道环。

## 拆解动画的通用语法(各部件复用)
打开 1.0 s:外壳整体分离并翻转 → 内部机械伸出 → 核心发光变亮。悬停:零件继续转,镜头慢推。合上 0.5 s。
腹部的"核心"是线圈,打开时是整个视频最亮的画面。

## 声音(用代码合成,避免版权)
- 0–1 s:轻轻淡入的氛围声。
- 1.0 s:一声轻响。
- 2.3–2.6 s:点击声 + 短促扫音。
- 2.5–5.2 s:外壳滑动声、线圈嗡鸣渐强、齿轮点点声。
- 5.0–5.2 s:点击声。
- 5.2–6.4 s:渐强上升音。
- 6.4 s:爆炸冲击 + 碎片声;慢动作段低频持续音。
- 7.6 s:倒放扫音(复位)。
- 8.3–8.6 s:点击声。
- 9.6–11.0 s:渐强上升音;11.0 s 出击"啪"的一声;最后 0.5 s 淡出。
- 响度统一到 -14 LUFS。

## 验收(只看大项,不抠细节)
1. 开场第一帧,螳螂占画面宽约 85%,且已在动。
2. 全片有且只有一个部件拆解,约 2.7 秒,打开时有玻璃壳分离翻转,露出发光核心。
3. 每个阶段的机位方位不同(相邻至少差 60°),拆部件时有推近。
4. 爆炸里有几百个小零件、轨道环、引线标注、330° 旋转和慢动作。
5. 光标移动并点击三次,与镜头切换对得上。
6. 页面有:品牌、标签、标题、按钮、4 张卡片、状态条、引线标注。
7. 收尾镰刀冲向镜头,最后一帧镰刀尖在镜头前。
8. 声音有渐强和淡出,点击声与光标对得上。
9. 成片 1080×1920,60fps。
