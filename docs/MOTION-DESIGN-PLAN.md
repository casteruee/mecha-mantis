## 2. 与原作者的差距（证据在 refgap 报告，此处浓缩为三条铁律）
原作者的"浑然天成"= **活体模型 × 不停摆镜头 × 转场呼吸 × 每拍对准自己的部位 × 镜头跟路径不跟摆动**。

### 差距 A：模型是活的（最大差距）
他的模型（ref-cutaway/sims/piranha-shared/tour_bee.js、piranha.js）每帧都在动：
- 尾摆 0.5Hz **全程不断**（"节拍之间模型自己动"）；
- **脊柱滞后弯曲**：7 关节各取 0.085s 前的机体姿态，转弯时整个身体甩弯；
- 整体姿态：多频正弦俯仰/滚转 + banking 入场（roll -22°）+ 蓄力后撤 + 弹射；
- 颌有 snap 咬合；摆尾时头反向微摆（重心守恒）。
我们 90% 时间躯干零动作；v9 第一期只是把几个正弦叠在手臂上——**没有预备/跟随、没有重量、没有行为序列**。

### 差距 B：镜头会呼吸
他源码注释里的两条铁律（照抄进设计）：
- "every close-up keeps pushing in through its whole act and keeps orbiting about 14°/s,
  **so a hold never parks**"——每个近景全程缓推+环绕，悬停永不静止；
- "Every beat gets its own **side, height and distance**, aimed at its part"（LESSONS.md）——
  眼=脸侧微距、尾=后方、腹=俯拍、下颌=仰拍，每拍对准**自己的部位**而不是几何中心。
- 转场 0.85s 混合 + **dolly-out 0.9 单位**的"吸气"（我们 v8 仅 0.06，差 15 倍）。
- "follows only the fish's path, never its sway"——镜头平滑，鲜活留给模型。

### 差距 C：开场是表演不是转盘
他的开场没有转台：模型 banking 自己"游"入英雄构图（尾摆、咬颔），相机轻环移；
"frame 0 is already the hero view... the fish big and moving"。我们的 360° 匀速转台=机械展台。

## 3. 原作者运动解剖（可移植机制清单）
源码位置：`ref-cutaway/sims/piranha-shared/piranha.js`（pose 系统）、`tour_bee.js`（节拍/镜头/飞行）。
| 机制 | 他的参数 | 移植到螳螂的对应物 |
|---|---|---|
| 姿势接口 | `pose({t, swim, bend, gape, eye, fin, lure, cage, flare, rib, drop, explode, spinT})` | `pose({t, life, gait, head, antenna, foreleg, breathe, ...})` |
| 游动节律 | swim 0.5Hz 尾摆 | 步态/重心转移 + 呼吸节律 |
| 脊柱滞后 | bend=7 关节取延迟姿态 | 触角/尾须/颊部延迟跟随；头-颈-胸链的跟随滞后 |
| 姿态势能 | flight 俯仰/滚转/偏航多频正弦 + 蓄力/弹射 | 警戒蓄力→弹击→回位（含预备/跟随） |
| 咬合 snap | gape 在关键时刻 0.12s 快照 | 前肢快弹（必须带预备）|
| 行为窗 | ACT.open/close 每部件独立时钟 | 每个行为有自己的窗（理臂/扫视/弹击） |
| 时间扭曲 | hero 时刻对齐音乐 drop | 撞击/出击对齐音效线索 |

## 4. 设计规划（四块，按优先级执行）

### A. 活体模型系统（P0，先做这个）
**A1 运动设计原则（必须写进代码注释并贯彻）**
- 弧线运动 + 慢进慢出；**禁止**线性正弦往复当"生命感"；
- 每个动作有**预备（anticipation）→ 主动作 → 跟随/滞后（follow-through）**；
- 不对称与错相：左右肢永不镜像同步（相位差 ≥1.2rad）；
- 三层叠加：大周期 4–8s（姿态游走/注意力）× 中周期 1–2s（肢体节律）× 小周期 0.2–0.5s（微颤）；
- 重量感：加速度可见、回位有阻尼过冲（≤5%）；
- **行为化**：动作是"行为序列"（有起止和注意力焦点），不是波形叠加。
**A2 螳螂行为库（替换 v9 第一期）**
- 头颈：扫视（快转 0.25s + 慢跟，目标处停 0.3–0.8s，随机换目标）；追踪前肢/镜头；
- **前肢理臂 grooming**（招牌行为，必须做）：前肢举到口器、胫节从"齿"间缓慢抽出、左右交替、每 ~20s 一轮；
- 前肢弹击试探：预备收缩 0.3s → 0.1s 弹出 → 0.5s 阻尼回位；两侧交替且非周期（±3s 抖动）；
- 前肢收举/放下（警戒姿态呼吸）；弹簧/活塞/履带等"细节动"保留但**幅度跟行为包络**（不是独立正弦）；
- 触角：双频摆 + 被扫视带动的滞后；呼吸：胸腹 0.6–1% 节律 + 翅微张合；
- 步态：原地重心转移/踏步（film 开头行走保留）。
**A3 合成规则**：生命层永远跑；行为层在节拍间插入（拆解悬停段继续"自己的动作"）；
与 strike/拆解为加法合成；纯函数 of t（render(t) 可重现）。

### B. 镜头呼吸（P1）
- B1 每拍机位三元组（az/el/d）两两不同、对准**该拍部位**（不是几何中心）；
- B2 **hold never parks**：每个近景内 d 全程缓推 ≥0.15、az/缓移 ≈10–14°/s；
- B3 转场 0.85s + **dolly-out 0.6–0.9** 呼吸（现 v8 pullback 0.06 必须加大）；
- B4 镜头跟"路径"不跟"摆动"；B5 加 1–2 个部位微距（眼部/弹簧）；B6 距离跨度拉开（微距 d≈5 → 远 16+）。

### C. 开场展示（P2，替换 360° 转台）
**方案 B（推荐）**：取消匀速转台。模型原地做生命表演（扫视/理臂/触角/呼吸辉光），
相机以景别滑移连续走：微距眼部 → 中景全身 → 低角度仰视 → 英雄位收束，每段缓推+环绕；
全角度读形用**相机环绕 360°**（模型在动）。备选 A：螳螂"走进"英雄构图（步态+警觉收举）。
转台如保留只允许一段慢速且模型同时有动作。

### D. 全片编排（P3）
- 节拍表方法：建立→英雄①→过渡→英雄②→出场（v8 已有骨架，配合 B 升级）；
- 音画同步：时间字段全部 `tools/mkvN.py` 生成+自检；音效 `tools/makesfx.py` 读 JSON 线索重合成；
- 拆解段节拍（v8）**保留**，只叠加活体层与镜头呼吸。

## 5. 验收标准（可测量，交片前自检）
1. 任意连续 2s 内，模型至少有一处**非往复**的有意义动作（逐帧抽样差分 + 目测）；
2. 拆解悬停段镜头 d 变化 ≥0.15、az 变化 ≥5°（campath 数值探针扩展输出）；
3. 每拍机位 (az, el, d) 与前后拍至少两项不同，且该拍画面中心落在本拍部位；
4. 转场 dolly-out 峰值 0.6–0.9；
5. 前肢行为（理臂/弹击）含预备与跟随，抽帧可见三段式；
6. 穿模探针 `tools/campath.js` 0 违规（红线 0.35u）；复位 `tools/resetprobe.js` 精确归零；
7. 技术项：16.5s/1080p60/990 帧/无黑帧/无爆音（volumedetect max<0dB）；
8. 最终标准 = Owner 看片满意（对照原片 `X-Nyxera0x-3D-Simulator-Part2.mp4` 的流畅感）。
