# 岗位说明书:机械生物 three.js 构建

你要根据一张参考图,用 three.js 全程写代码,构建一个机械生物,并能逐个部件拆解。不导入任何 3D 模型、贴图或图片,所有外壳、齿轮、尖刺都是代码生成的。参考图只用来对照,不能导入。

## 外观规则
- 白色亮面外壳:clearcoat 加环境光贴图(用 RoomEnvironment + PMREM 生成)。
- 洋红(magenta)只做稀疏点缀:镰刀尖、板片边缘、边线、关节环、发光线圈。绝不能把洋红点撒在外壳上。
- 深色机械分两层:大件(齿轮、环、作动器)和约 260 个小件(活塞、软管、螺丝、线束)。外壳上要开窗,让深色机械露出来。
- 眼睛:亮黑色镜片,细洋红圈,小瞳孔。
- 翅膀、薄膜:乳白磨砂,带细脉。
- 每条肢体有自己的姿态和节长,绝不能是一排完全相同的部件。
- 刺毛和尖刺要又细又短:粗细为所在肢节的 0.15 到 0.25。
- 每个生物只有一组主要肢体(螳螂是前面那对镰刀前臂),其他肢体要弱化,不能抢戏。
- 近白色摄影棚背景,柔和地面阴影。

## 构建顺序
1. 先量参考图:总长、头、前臂、腹部等主要比例,写成占体长的比例,记在检查清单的"实测比例"里。
2. 搭出物体,渲染一张姿态和参考图一致的静帧(1600×900)。
3. 把参考图、你的静帧、上一轮通过的静帧并排,对检查清单每一条打分:是 / 部分 / 否。对着图打分,不要凭记忆。
4. 每轮多加一条检查:缩成 900px 宽的缩略图,密度是否和参考图一样?
5. 量密度:取物体外框,数暗色像素(亮度 < 80)占比,你的占比要达到参考图的 0.8 倍以上,否则算"否"。提高的方法是把白色表面拆成分开的板片,中间留缝透出机械,堆小点不算。
6. 第 2 轮结束后停下来给我看,我点头之前不许做影片。

## 镜头规则
- 第 0 帧:正面三分之四的英雄视角,物体很大,而且已经在动。
- 每个拆解部件都有自己的方位、高度和距离,镜头对准那个部件,在它打开时推近(眼睛做宏观、尾部从后面、背部从上面、颚从下面)。
- 被打开的部件始终在画面里,其他部分可以出画。
- 只用平滑的镜头路径,镜头不跟着翅膀或脚步抖动。
- 可见的翅膀拍动保持缓慢,1.5 到 2.5 Hz。

## 影片规则
- 完整版约 21 秒:每 2 到 3 秒拆一个部件,然后整体爆炸(330° 旋转)、快速复位、退场。
- 部件约 1 秒打开,保持时零件继续转动,0.5 秒合上。
- 整部影片由一个 JSON 脚本驱动(物体、页面、音效都读同一个脚本)。
- 短版(10 秒)是单独的脚本:开场、一个部件、爆炸、退场,不是把长片剪短。
- 渲染要按帧,render(t) 是时间的纯函数。

### 纠正记录(螳螂,第 2 轮后)
1. 打分要对着参考图的结构打,不能只核对"有没有这个部件"。后腿:参考图是白色股节壳(厚约 0.034 L)加深色金属胫节(约 0.012 L),关节弯折。四根直细杆只算"部分"。颈部:参考图颈部更粗(约 0.09 L),有开窗。细管只算"部分"。
2. 全框暗像素占比会失效:黑色细腿和成片的平黑板就能把它刷过线。改成三条,都要对参考图用同一方法量:
   - 身体区域暗像素(亮度 < 80)占比 ≥ 参考图的 0.8 倍。身体区域 = 物体去掉 4 条走路腿和天线。
   - 边缘密度 ≥ 参考图的 0.8 倍。边缘密度 = 900px 宽缩略图上,身体区域内 Sobel 梯度幅值 > 60 的像素占比。
   - 任何连通的纯黑块(亮度 < 30)面积 ≤ 画面的 0.5%。
3. 体量按参考图实测比例做,不要凭感觉:胸部厚 0.22 L,腹部最大厚度 0.23 L,腹部是鼓起的椭球(长厚比约 1.8),不能是细管加环;前胸厚约 0.09 L;头高约 0.15 L。
4. 材质和光:先确认 RoomEnvironment 环境贴图和 clearcoat 确实生效(开关对比一次);外壳要有厚度和倒角,不能是单层薄面;要有一盏从后上方来的轮廓光;背景用近白的竖直渐变;地面阴影用柔和的接触阴影(从下往上的剪影加模糊),不能只靠一张硬的 shadow map。
5. 腹部:玻璃板要真有玻璃感(transmission 折射,不是降低 opacity);线圈自发光,加选择性 bloom,只让线圈发光。
6. 前臂股节:做成又大又白的玻璃椭圆壳,宽约 0.12 L,弹簧从里面透出来,深色只留在中间一条细机械带。
7. 后腿:上段白色亮面壳加粗,下段细金属杆,关节弯折;四条的姿态和节长都不一样。
8. 翅膀:抬离腹部约 10°,长约 0.59 L,宽约 0.11 L,乳白磨砂,带粉色细脉。
9. 眼睛:参考图没有可见瞳孔。眼睛是亮黑玻璃圆顶加洋红边,一半嵌在头壳里,不能像耳机一样架在头顶。
10. 约 260 个小件用 InstancedMesh 生成。
11. 每轮除了英雄静帧,还要渲染前臂、头、腹部三张特写,分别和 ref-forearm-macro / ref-head-macro / ref-abdomen-macro 1:1 并排打分。

### 纠正记录(螳螂,第 3 轮后)
1. 机位和翅膀:先从参考图量出相机的仰角和偏转角(用模型特征点对参考图的像素位置反求相机),再把仰角抬高到 15° 到 20°,FOV 25° 到 30°(长焦产品照)。英雄图外框要达到 0.81 宽 × 0.89 高(误差 ±0.02),只能调相机距离和姿态,不能改模型尺寸去凑。翅膀相对身体轴线上抬 15° 到 20°,做成有弧度(横向和纵向都拱起)、有厚度(双层面加边缘圆管)的片,长约 0.59 L、宽约 0.11 L,保留粉色细脉。
2. 腿是"像示意图"的最大来源。按参考图实测做:白色股节壳粗 0.030 到 0.034 L;深色金属胫节上段(活塞套)粗约 0.012 L,下段约 0.007 L;近处后腿长度为股节 0.28 L、胫节 0.31 L、跗节 0.06 L(合计约 0.65 L);中腿更短。关节要弯折,不要直杆;四条的姿态和节长都不一样。
3. 胸部和颈部:白方砖改成有弧度的大块叠压壳(每侧 4 到 6 块,每块约 0.28 体节长 × 0.75 rad,相邻两块的半径差约 3%),带倒角,板边加细洋红线(粗约 0.012)。颈部做成宽白板(覆盖约 ±1.5 rad)加玻璃窗,不能是黑管。
4. 头:头壳更厚实(前后厚度 ≥ 头宽的 0.55 倍)。眼睛是嵌进头壳的大椭圆玻璃圆顶(长宽比约 1.5,不要圆球,也不要瞳孔),边缘有细洋红线。天线从头顶前方、两眼之间长出来,不是从眼睛后面长出来。
5. 前臂:刺是深色金属细针,针尖约 20% 的长度是洋红,每节 15 到 20 根;膝关节用白色关节盖(白壳加中心螺丝加细洋红环),不要黑圆盘。前臂特写只框一条前臂的侧面,背景用浅景深(BokehPass)虚化。
6. 腹部:白环收窄到约 0.01 L,环与环之间的玻璃要有可见的纵向板缝和反光;内部黑色空腔用齿轮和小零件填满;保留现在的线圈发光和光晕。腹部特写的机位要避开腿的遮挡。
7. 保留:clearcoat 高光、柔和接触阴影、近白渐变背景、腹部 bloom。
8. 指标:英雄图和三张特写的最大连通纯黑块(亮度 < 30)都要 ≤ 画面的 0.5%;三张特写的边缘密度都要 ≥ 对应 macro 参考图的 0.8 倍。

### 纠正记录(螳螂,第 4 轮后,最后一轮静帧)
1. 机位:仰角 10°、偏转 26°、FOV 28°。翅膀保持上抬,靠翅膀的侧倾角(约 0.3 rad)让它在这个仰角下仍能读成一片。胫节长度恢复到参考图实测比例(后腿胫节约 0.31 L,中腿相近),不准为了外框加长。外框宽度接受 ≥ 0.75,不为宽度牺牲腿的比例。
2. 暗部:恢复分层的深色零件,不准整体提亮。胸部和腹部内部要有深色背景,把发光线圈衬出来。身体暗像素 ≥ 参考图的 0.9 倍;腹部特写暗像素 ≥ 对应 macro 参考图的 0.8 倍。
3. 发光:线圈用饱和洋红(接近 #ff1fd0),不准发粉白。emissive 强度降到不过曝(约 1.0),bloom 只作用在线圈上,tone mapping 用 Neutral 或 AgX。
4. 关节:不准做同心圆"靶心"(白盘加洋红圈加黑点)。关节盖是素白的,中间只有一颗小螺丝(直径约为盖子的 0.25)。洋红只出现在板片边缘线、镰刀尖和线圈上(另外保留眼睛的细洋红圈和翅膀的粉色细脉)。
5. 眼睛:深黑亮面,只靠高光反射显出形状,不能是灰紫色;洋红圈要细(管半径约 0.008)。头部特写用参考图那样的三分之四侧脸。
6. 刺:基部宽度 ≤ 刺长的 0.2,针状、微弯、朝外张开(两排交错,左右各偏约 30°),不准沿边缘排成一排锯齿。
7. 胸部:白板边缘的洋红线只保留约一半;板与板之间留深色缝(约 0.04 rad / 0.03 体节长),不能像纸模。
8. 特写:前臂特写一条前臂居中、镰刀尖完整、没有中腿挡在前面;腹部特写避开后腿。
9. (补充 A,优先)头:整体向下低头约 25°(在 20° 到 30° 之间),朝向前臂。头壳更宽更厚(宽约为原来的 1.15 倍),从两眼之间一直包到嘴部,正中有一道 V 形棱。眼睛是长宽比约 1.6:1 的长椭圆黑色玻璃,上端向中线微倾(约 10°),嵌在头壳里。洋红线沿头壳上的眼窝边缘走(比眼睛大约 8%,贴在壳面上),不要套在眼球外面。嘴部加一组小而密的深色零件(约 12 个)。天线从两眼之间的头顶前方长出,向后弯。
10. (补充 B,优先)板片之间的缝里要塞进链条履带、软管、小齿轮和线束,从缝里露出来;只加铆钉和描边不算。胸部、前臂股节下方、腹部两端各加一段履带状链节(参考 ref-head-macro 里的脖子)。
11. (补充 C,优先)头部特写和 ref-head-macro 的角度对齐:三分之四侧脸,机位略低于头(仰角约 -5° 到 0°),浅景深。
12. (最后一轮静帧的总目标)不再逐条对标参考图,而是做好三个看点:①头和眼睛;②前臂的白色玻璃壳、内部弹簧和洋红镰刀;③腹部的发光玻璃。身体其余部分保持干净简洁即可。数字要求和上面第 1 到 11 条相同:机位仰角 10°、偏转 26°、FOV 28°;外框宽度接受 ≥ 0.75;胫节按实测比例;身体暗像素 ≥ 0.9 倍;腹部特写暗像素 ≥ 0.8 倍;线圈颜色接近 #ff1fd0;洋红不出现在关节上。

### 工作方法纠正(第 6 轮后,r7 起执行)
1. 形状性部件(头壳、眼、翼型等)禁止在变形球上盲调参数:先用网格从参考图描出目标几何(轮廓控制点 / 椭圆轴 / 倾角 / 轴向倾角),写成坐标表,再照表建模(轮廓放样);每步渲染与描摹线叠图核对,线重合才算过。
2. 机位对齐先于形状对齐:特写机位(方位/仰角/构图)先和参考图一致再比形状,否则视角差会掩盖或放大形状差。
3. 眼睛类镜面件的高光用细长条光源环境(禁大块面反射);眼眶环只留贴壳侧的弧段,不许整圈(侧视会穿帮成直线)。
